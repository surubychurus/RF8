# Tipografías (placeholder)

1. Copiá acá los archivos `.ttf` / `.otf` de las tipografías de RF8.
2. Descomentá el bloque `fonts:` en `pubspec.yaml` y ajustá nombres/archivos.
3. En `lib/theme/brand.dart` completá `Brand.displayFont` (títulos) y
   `Brand.bodyFont` (textos) con el `family` declarado en el pubspec.
