# Logo (placeholder)

Colocá acá el logo de RF8 como `logo.png` (fondo transparente, cuadrado,
idealmente 1024×1024). La app lo toma automáticamente; mientras no exista,
muestra un placeholder con las letras "RF8".

Para usar otro nombre o formato, cambiá `Brand.logoAsset` en `lib/theme/brand.dart`.
